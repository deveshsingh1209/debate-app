## User experience

Unchanged on every first-class setup (Claude login, Claude API key, Codex login, OpenAI key): no new step, no new screen, no launch token. What a user can notice:

- An upload's hidden files are skipped with a note, and a `CLAUDE.md` in an upload is listed as `_CLAUDE.md`.
- A research question carrying a link is not sent, and the room says so in one system line.
- The panel architect makes one extra call (the web pass) on the Claude and Codex doors. Quality over cost: the designer keeps its web grounding, it just gets it as a fenced note.
- Docker users no longer have to invent a password; they read it from the logs or `./data/.access-password`.
- Behind an HTTPS reverse proxy that sends no `X-Forwarded-Proto`, set `PUBLIC_URL` (README says so).

## Residual risk (also in SECURITY.md "Known limits")

- **Live confirmation of the python read denials (audit re-test R-1) is still owed.** The rules are verified offline in the options every python turn is built with; whether the installed Claude Code CLI's sandbox enforces each of them (and the `**/.env` glob on Linux) needs one owner-approved live quant turn that tries `open(os.path.expanduser('~/.codex/auth.json'))`.
- **WebSearch result format.** The search-result registry extracts every `http(s)` URL from the WebSearch tool result, in whatever shape it arrives, from two sources (the hook and the stream). If a future CLI returned results without URLs, research would still search but could not open pages; it would fail closed, not open.
- **DNS rebinding against the CLI's own lookup** is not fully closable without fetching pages ourselves; the before-and-after checks and the search-result rule limit it to one fetch whose content cannot leave.
- **Prompt injection is reduced, not solved.** The fences and the tool layout are built so a successful injection has little to work with.
- Findings 6 (report CSP, PDF `--no-sandbox`), 11 (redaction on the Claude error path), 12 (GET side effects) and 13 (`/api/health` detail) were outside this brief and are unchanged.
